# Dashboard

`index.html` is the shareable experiment board — published as a private
artifact and readable by someone who has not seen the repository.

It is **hand-maintained and will go stale.** The numbers on it come from the
toolchain (`experiments/ROADMAP.md`, `hamiltonian.experiments`,
`compare.corrections`) but nothing regenerates it, so check it against those
before sharing it again after any real result lands.

Self-contained apart from Google Fonts: no build step, no assets. Open it in a
browser, or republish it as an artifact.

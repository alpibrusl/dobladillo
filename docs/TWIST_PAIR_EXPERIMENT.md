# The twist pair

An experiment design to hand to a group with an AFM. Two samples, one session.

Source of record; a formatted version is published separately. Every number is
generated by the toolchain (`dobladillo twist-pair`), not typed.

## The question

The square lattice fixes crossovers so 32 bp spans three turns, which is 10.67
bp/turn against B-DNA's relaxed 10.5. The mismatch accumulates and over-winds
the sheet. The remedy is periodic single-base deletions.

**Our toolchain derives the period rather than copying it:** a 64-base span is
6 turns by the lattice's reckoning, relaxed DNA wants 6.095, and removing one
base makes it exactly 6.000. Published designs commonly use 48, which does not
cancel exactly. `constants.py` flags that as unresolved because it is an
empirical question. This answers it.

## The pair

Identical except for one thing.

| | Arm A, corrected | Arm B, uncorrected |
|---|---|---|
| Difference | 108 deletions, one every 64 | none |
| Geometry | 12 x 576 bp | 12 x 576 bp |
| Size | 191 x 36 nm | 191 x 36 nm |
| Scaffold routed | 6804 nt | 6912 nt |
| Staples | 216, 30-32 nt | 216, 32 nt |
| Plates | 3 x 96 | 3 x 96 |
| **Predicted** | lies flat on mica | 309 deg of twist; cannot lie flat |

**Why a pair.** A single measurement that agrees can agree by luck. A pair
compares the *difference*, which is much harder to get right by accident, and
it cancels every shared source of error at once: same scaffold lot, buffer,
anneal, operator, session.

## Why this shape

Twist accumulates along the helix; cost is set by scaffold routed. So signal is
nearly free.

| Geometry | Size | Staples | Cost | Uncorrected twist |
|---|---|---|---|---|
| 22 x 320 | 106 x 66 nm | 220 | 693 | 171 deg |
| **12 x 576** | 191 x 36 nm | 216 | 680 | **309 deg** |
| 8 x 896 | 298 x 24 nm | 224 | 706 | 480 deg |

The longest has the most signal but becomes a 24 nm ribbon: floppy and awkward
to classify. At 36 nm it still reads as a rectangle.

## The readout, and what could spoil it

**Mica flattens what it adsorbs.** A twisted sheet may be forced flat, hiding
what we came to see. So the question is not "does this particle look twisted"
but:

- **what fraction lies flat as a clean rectangle**, per arm, from the same
  number of particles;
- what fraction appears rolled, tubular, or as a distorted parallelogram;
- whether the flat ones in arm B are systematically shorter along one axis.

If both arms behave the same, that is the interesting result: the correction is
unnecessary, and we stop building it into every design.

The document asks the group directly whether the flattening makes this
unmeasurable in air, whether liquid would preserve it, and whether a gentler
deposition would let a strained object keep its shape.

## Asking for

Two samples, one session, same settings. 2 x 2 um for counting, 500 x 500 nm
for dimensions. **At least 100 particles per arm, 300 if cheap** -- at 100 a
fraction near 70% carries +-9%, at 300 about +-5%, and below 100 the arms could
differ a lot and still not be distinguishable. Native instrument files.

About EUR 1400 in oligos for both arms, same scaffold.

## Why this and not the dimer

The roadmap's next item is a two-brick dimer (M5b). That needs interfaces, an
orthogonality matrix and assembly planning built first, and its failure modes
are ambiguous: a dimer that does not form could have failed at the interface,
the folding or the purification. This needs nothing that does not already
exist, and both arms pass the design rules with no violations -- which matters,
because an uncorrected arm that broke a rule would confound the result.
